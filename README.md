# HRM (Human Resource Management) System

This project analyzes and designs a Human Resource Management system with 6 core functional groups:

1. Employee Profile Management
2. Department/Unit Management
3. Reward/Discipline Management
4. Attendance Management
5. Contract Management
6. Salary Management

Current focus: **Salary Grade Promotion** ("Xét nâng bậc lương"), a feature under **Salary Management**.
