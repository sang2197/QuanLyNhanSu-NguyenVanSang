# HRM (Human Resource Management) System

This project analyzes and designs a Human Resource Management system with 6 core functional groups:

1. Employee Profile Management
2. Department/Unit Management
3. Reward/Discipline Management
4. Attendance Management
5. Contract Management
6. Salary Management

Current focus: **Salary Grade Promotion** ("Xét nâng bậc lương"), a feature under **Salary Management**.

## Design Documents (`Docs/`)

- **`Quản lý nhân sự.xmind`** — Top-down mind map breaking down the whole HRM system into the 6 function groups above, down to feature-level detail.
- **`HRM_Salary_Grade_Promotion_Database_Design_EN.docx`** — Database design for the Salary Grade Promotion feature (tables, fields, relationships).
- **`HRM_Salary_Grade_Promotion_Wireframe_UIUX_EN.docx`** — UI/UX wireframes for the Salary Grade Promotion feature (screens and user flow).
- **`DB_Diagram.png`** — Entity-relationship diagram (from dbdiagram.io) visualizing the 8 database tables for Salary Grade Promotion and their relationships.
- **`Gen_Table.sql`** — SQL script (generated from dbdiagram.io) to create the 8 database tables, keys, indexes, and foreign keys for Salary Grade Promotion.
